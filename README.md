# Travelling Pro

...in progress

Multiplatform (iOS & macOS) application, which gives a convenient way to collect all countries that you have visited.

## PROJECT SPECIFICATION

• Operating system: [iOS](https://www.apple.com/ios/) / [macOS](https://www.apple.com/macos/);

• Programming language: [Swift](https://developer.apple.com/swift/);

• Interface: [SwiftUI](https://developer.apple.com/xcode/swiftui/);

• Database: [Cloud Firestore](https://firebase.google.com/docs/firestore);

• Object storage service: [Cloud Storage for Firebase](https://firebase.google.com/docs/storage);

• Authentication: [Firebase Authentication](https://firebase.google.com/docs/auth);

• Analytics & Crash Reporting: [Firebase Crashlytics & Analytics](https://firebase.google.com/docs/crashlytics);
